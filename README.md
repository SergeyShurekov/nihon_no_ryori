# Nihon no Ryori

## 日本語

### 概要

`Nihon no Ryori` は、日本料理をテーマにした小さなレシピカタログアプリです。  
React と Vite で構築されており、家庭で作りやすい料理を一覧と詳細ページで閲覧できます。

> **公開中の実例はこちら:** [https://nihon-no-ryori.vercel.app/](https://nihon-no-ryori.vercel.app/)  
> **現在動作しているサンプルをそのまま確認できます。**

このアプリでは、主に次のようなことができます。

- 日本料理のレシピを一覧表示する
- カテゴリで絞り込む
- キーワードで検索する
- レシピ詳細ページで材料と作り方を確認する
- `JP / RU` の言語切替を行う
- 初回アクセス時にブラウザ言語に応じて表示言語を自動選択する

### プロジェクト内容

アプリには以下のような要素が含まれています。

- ホームページ
- 共通 `Header` / `Footer`
- レシピ一覧カード
- レシピ詳細ページ
- 日本語 / ロシア語のUI切替
- ローカルSVGイラストによる料理ビジュアル

### 技術スタック

- React
- Vite
- React Router
- ESLint

### 起動方法

#### 1. 依存関係をインストール

```bash
npm install
```

#### 2. 開発サーバーを起動

```bash
npm run dev
```

起動後、Vite が表示するローカルURLをブラウザで開いてください。

### 利用できるコマンド

```bash
npm run dev
```

開発サーバーを起動します。

```bash
npm run build
```

本番用ビルドを作成します。

```bash
npm run preview
```

ビルド済みアプリをローカルで確認します。

```bash
npm run lint
```

ESLint によるコードチェックを実行します。

## Русский

### Описание

`Nihon no Ryori` — это небольшое приложение-каталог рецептов японской кухни.  
Проект собран на React и Vite и позволяет просматривать домашние японские блюда в виде списка и на отдельной странице рецепта.

> **Действующий образец проекта:** [https://nihon-no-ryori.vercel.app/](https://nihon-no-ryori.vercel.app/)  
> **По этой ссылке доступна опубликованная рабочая версия сайта.**

В приложении можно:

- просматривать каталог японских рецептов
- фильтровать рецепты по категориям
- искать блюда по названию
- открывать страницу рецепта с ингредиентами и шагами приготовления
- переключать интерфейс между `JP / RU`
- автоматически выбирать язык при первом запуске по языку браузера

### Что есть в проекте

Проект включает:

- главную страницу
- общий `Header` / `Footer`
- карточки рецептов
- страницу подробного описания рецепта
- переключение интерфейса на японский и русский языки
- локальные SVG-иллюстрации блюд

### Технологии

- React
- Vite
- React Router
- ESLint
